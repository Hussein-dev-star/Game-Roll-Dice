# 🎲 Gambler Inn - Dice Game

A simple console dice game in **C#** where you play against an AI.  

---

## 📝 Features

- Player vs AI dice rolls 🎲  
- Tracks points across 5 rounds  
- Input validation for `y/n` choices ✅  
- Clear console messages with emojis 😄  
- Clean and modular code using methods  

---

## 🎮 How to Play

1. Run the program.  
2. Type **`y`** to start or **`n`** to exit.  
3. Press **Enter** to roll the dice each round.  
4. Scores are displayed after each round.  
5. After 5 rounds, the final winner is announced.  

---

## 🛠️ Concepts Used

- Variables and loops  
- Methods and `ref` parameters  
- Input validation  
- Random number generation  
- If/Else statements
